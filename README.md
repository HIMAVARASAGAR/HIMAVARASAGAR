### Projects

#### Graphene THz MIMO Antenna
A 2-element terahertz MIMO antenna array modeled with graphene patches for the 0.8–1.2 THz band. Used machine learning regression to predict resonance frequency shifts across geometric variations instead of running repeated full-wave EM solver sweeps.
* **Tools**: CST Microwave Studio, HFSS, scikit-learn, NumPy

#### Universal Cognitive Engine
A multi-agent execution framework built with the Google Agent Development Kit (ADK). Implements structured tool calling, state persistence across execution steps, and hierarchical subagent delegation.
* **Tools**: Python, Google ADK, Pydantic

#### ESP32 Telemetry
Firmware and ingest pipeline for streaming sensor data from an ESP32 over UDP into an asynchronous Python listener, with n8n workflows for automated logging and alerts.
* **Tools**: ESP32, C++, Python, UDP, n8n

#### csage
A Python utility package published on PyPI for structured data operations and compute workflows.
* **Tools**: Python, Poetry, PyPI
